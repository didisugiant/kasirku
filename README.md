# 💰 KasirKu — Catatan Keuangan + AI Premium

Aplikasi pencatatan keuangan dengan AI konsultan dan sistem pembayaran premium via Midtrans.

## 🚀 Quick Deploy

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

## 📦 Fitur

- ✅ Catat pemasukan & pengeluaran
- ✅ Export laporan ke Excel (3 sheet berwarna)
- ✅ AI Konsultan Keuangan (OpenAI GPT-3.5)
- ✅ Sistem Premium (Midtrans Payment Gateway)
- ✅ QRIS, GoPay, Transfer Bank, Gerai Retail
- ✅ Responsif di semua handphone
- ✅ Data tersimpan di localStorage

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Backend:** Node.js + Express
- **Payment:** Midtrans Snap
- **AI:** OpenAI GPT-3.5-turbo
- **Spreadsheet:** SheetJS (xlsx)
